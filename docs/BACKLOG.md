## Технический долг
- [ ] **P2. Каталог предметов из другого источника.**
  - Инвентарь берёт предметы из 5e-database (SRD 5.2) и `inventory_text_ru.json`, а классы, заклинания и контейнеры — из Foundry.
  - В SRD меньше предметов, чем в PHB 2024, и около 10 предметов стартового снаряжения не сопоставляются по названию.
  - Перевести инвентарь на Foundry, как остальной каталог.
- [ ] **P2. Код-ревью последних больших фич:** контейнеры, владения и мастерство, мастерская кубиков, переход JSON и рендера кубиков.
- [ ] **P3. Размерные токены не проведены в код.** В `design_tokens.json` есть `spacingDp`, `radiiDp`, `strokesDp`, но `DesignTokens.kt` их не читает, а `LocalDnDSpacing` нигде не используется: отступы и радиусы пишутся числами. Самый частый радиус в коде — 10dp (45 раз) — в JSON отсутствует. Решить: завести недостающие значения и читать токены, или убрать мёртвые группы.
- [ ] **P3. Разбить огромные экраны.**
  - `InventoryScreen.kt` — около 2800 строк, `CombatScreen.kt` — около 2600, `OverviewScreen.kt` — около 2300.
  - `AttributesScreen.kt` — около 1700, `LevelUpWizard.kt` — около 1500, `LevelUpEngine.kt` — около 1300.
- [ ] **P3. Старые степперы на `StepButton`.** «−/+» в бою (`StepperButton`, `AttackDialogStepperButton`, `CombatCompactNumberStepperField`) и в инвентаре (`StepperButton`, `CompactNumberStepperField`) — приватные копии в старом виде (обводка, подложка почти цвета карточки). Перевести на общий `StepButton` с заливкой кнопки.
- [ ] **P3. Перед первым релизом схлопнуть миграции базы.** Их больше 50, а пользователей нет: можно начать схему заново.
- [ ] **P3. Переезд на все платформы (Compose Multiplatform).** JSON и рендер кубиков уже переносимы. Остались:
  - Room 2.6: в версии для Multiplatform другой API миграций;
  - системные окна выбора и сохранения файлов (SAF);
  - загрузка картинок: портреты (`AppImage`) и импорт картинок скинов (`DiceSkinStore`);
  - звук (`MediaPlayer`), `LocalContext`, `android.util.Log`;
  - шрифты кубиков из `AssetManager`, декодирование картинок в `DicePictures.kt`.
  - Для iOS нужен Mac или облачная сборка.
