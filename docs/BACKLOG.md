# Бэклог

Хотелки, баги и технический долг. Приоритет: **P1** — нужно в ближайших играх, **P2** — важно, но может подождать, **P3** — когда-нибудь.
Сделанное переезжает в «Готово» с датой. Новый пункт — в свой раздел, коротко: что и зачем.

## Хотелки

### Игра за столом
- [ ] **P1. Броски с листа.**
  - Тап по атаке бросает d20 + модификатор на попадание, затем урон; при крите кубы урона удваиваются.
  - Тап по навыку, спасброску, проверке характеристики или инициативе бросает d20 с нужным модификатором.
  - Преимущество и помеха.
  - Итог с расшифровкой: «14 + 5 = 19».
  - Всё через 3D-стол, тихих случайных чисел не бывает.
- [ ] **P1. Состояния и истощение.**
  - Состояния: сбит с ног, отравлен, ослеплён и остальные.
  - Истощение по правилам 2024: −2 ко всем броскам d20 за каждый уровень.
- [ ] **P1. Концентрация.** Показывать, на каком заклинании держится концентрация. При уроне напоминать о спасброске Телосложения со СЛ max(10, половина урона).
- [ ] **P2. Сотворение заклинания.**
  - Тап по заклинанию: выбрать круг ячейки и списать её.
  - Включить концентрацию.
  - Бросить атаку или урон, показать СЛ спасброска.
- [ ] **P2. Сопротивления и иммунитеты** к урону и состояниям.
  - Character Wizard их уже вычисляет (defenses в итогах), но у персонажа нет поля.
  - Дизайн пока не решён: «подумаем».
- [ ] **P2. Урон при 0 хитов.** Любой урон — провал спасброска от смерти, критический — два; урон не меньше максимума хитов убивает сразу.
- [ ] **P3. Журнал бросков:** история последних бросков с расшифровкой.

### Character Wizard
- [ ] **P2. Понижение уровня.** Сейчас откатить уровень нельзя («недоступно»).
- [ ] **P2. Кости хитов при мультиклассе:** раздельные пулы по классам на коротком отдыхе, броски через 3D-стол.
- [ ] **P3. Заклинания эльфийского наследия на 3 и 5 уровнях.** Нужны вложенные шаги видовых особенностей на поздних уровнях.

### Инвентарь
- [ ] **P2. Настройка (attunement) магических предметов:** не больше трёх, отметка на предмете. Каталог про настройку знает, инвентарь нет.

### Кубики
- [ ] **P3. Делиться скинами:** экспорт и импорт скина файлом (JSON и картинки), чтобы отправить друзьям.

### Тексты
- [ ] **P3. Английские тексты каталога:** не хватает 73 названий и 749 описаний. Список лежит в `tools/foundry_catalog/translations/missing_en.json`, переводы пишутся в `translations/en.json`.

## Технический долг
- [ ] **P2. Каталог предметов из другого источника.**
  - Инвентарь берёт предметы из 5e-database (SRD 5.2) и `inventory_text_ru.json`, а классы, заклинания и контейнеры — из Foundry.
  - В SRD меньше предметов, чем в PHB 2024, и около 10 предметов стартового снаряжения не сопоставляются по названию.
  - Перевести инвентарь на Foundry, как остальной каталог.
- [ ] **P2. Код-ревью последних больших фич:** контейнеры, владения и мастерство, мастерская кубиков, переход JSON и рендера кубиков.
- [ ] **P3. Разбить огромные экраны.**
  - `InventoryScreen.kt` — около 2800 строк, `CombatScreen.kt` — около 2600, `OverviewScreen.kt` — около 2300.
  - `AttributesScreen.kt` — около 1700, `LevelUpWizard.kt` — около 1500, `LevelUpEngine.kt` — около 1300.
- [ ] **P3. Перед первым релизом схлопнуть миграции базы.** Их больше 50, а пользователей нет: можно начать схему заново.
- [ ] **P3. Переезд на все платформы (Compose Multiplatform).** JSON и рендер кубиков уже переносимы. Остались:
  - Room 2.6: в версии для Multiplatform другой API миграций;
  - системные окна выбора и сохранения файлов (SAF);
  - загрузка картинок: портреты (`AppImage`) и импорт картинок скинов (`DiceSkinStore`);
  - звук (`MediaPlayer`), `LocalContext`, `android.util.Log`;
  - шрифты кубиков из `AssetManager`, декодирование картинок в `DicePictures.kt`.
  - Для iOS нужен Mac или облачная сборка.
