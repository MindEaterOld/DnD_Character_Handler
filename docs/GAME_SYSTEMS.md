# Игровые системы — план (2026-10-10)

Желание владельца: приложение не только под D&D 5e (2024), но и под D&D 5e (2014), Pathfinder, Starfinder,
Vampire: The Masquerade. Персонаж привязан к одной системе и в других не существует. Система выбирается
в шторке персонажей, самой верхней карточкой; от выбора меняется список персонажей, правила, поля листа.
Интерфейс стараемся держать похожим, но листы систем будут отличаться.

Работаю по этапам сверху вниз; каждый этап — сборка, тесты, эмулятор, отдельный коммит.

## Словарь

- **Семейство** (`GameSystemFamily`) — игра: Dungeons & Dragons, Pathfinder, Starfinder, Vampire: The Masquerade.
- **Система** (`GameSystem`) — редакция игры, в которой сделан персонаж: D&D 5e (2024), D&D 5e (2014),
  Pathfinder 2e, Pathfinder 1e, Starfinder 2e, Starfinder 1e, Vampire V5. У каждой свой ключ (`dnd5e_2024`, `pf2e`…):
  он хранится у персонажа, в архиве `.dndchar` и в настройках — **ключ никогда не меняется**.
- **Доступна** (`available`) — у системы есть правила и лист. Сейчас только D&D 5e (2024). Остальные видны
  в выборе приглушёнными, с пометкой «В разработке», и не нажимаются (решение владельца, 2026-10-10).

## Этап 1. Персонаж привязан к системе — данные

- [x] `GameSystem` и `GameSystemFamily` (`domain/model/GameSystem.kt`), названия в `localization.json`.
- [x] Колонка `characters.gameSystem` (миграция 55 → 56): все нынешние персонажи — `dnd5e_2024`.
- [x] `Character.gameSystem`; новый персонаж создаётся в выбранной системе.
- [x] Архив: `gameSystem` в манифесте (схема 27). Старый архив без ключа — D&D 5e (2024). Архив
      незнакомой или недоступной системы не импортируется (сообщение об ошибке).
- [x] Выбранная система в настройках (`game_system`), по умолчанию D&D 5e (2024).

## Этап 2. Шторка — карточка системы и выбор

- [x] Верхняя карточка шторки: эмблема семейства, название игры, редакция; тап открывает выбор.
      Это ячейка со значением, а не кнопка: обводка без заливки (правило кнопок и статов).
- [x] Выбор — шторка снизу (`EditSheet`): группы по семействам, редакции — переключатели; выбранная золотом,
      недоступные с пометкой «Скоро». Выбор применяется сразу.
- [x] Список персонажей — только выбранной системы. При смене системы выбирается последний персонаж этой
      системы (по времени правки); если их нет — шторка остаётся открытой, как при первом запуске.
- [x] Пусто: в доступной системе — «Здесь пока нет персонажей» и «Новый персонаж»; в недоступной —
      «Листы персонажей для … пока в разработке», кнопки создания нет.
- [x] Импорт переключает выбранную систему на систему персонажа из архива.
- [x] Доска вариантов карточки (обе темы): владелец выбрал A (2026-10-10).
- [x] Родные эмблемы игр вместо куба (2026-10-10): амперсанд D&D, глиф Pathfinder Society, звезда Starfinder
      Society, анх «Вампиров» (обведён по картинке владельца).
- [x] Архив: система отмечена дважды — в шапке и в самом персонаже; чужая система или разные пометки —
      архив не открывается (проверено тестами и на эмуляторе, 2026-10-10).
- [ ] Арты игр на фон карточки — когда будут.

## Этап 5. Лист как модуль системы — когда появится вторая система

Не делаю сейчас: без второй системы не видно, что на самом деле общее. Направление:
- Общая часть персонажа — `id`, имя, портрет и кадр, система, время правки, заметки, биография — то, что
  видит шторка. Для строки шторки система даёт свою подпись (в D&D «Эльф • Воин», «III LVL»; у вампира —
  клан и поколение).
- Модуль системы (`GameSystemModule`): вкладки листа, новый персонаж, архив, каталоги, правила. Импорт читает
  пометку системы в архиве и отдаёт его читателю этой системы; читатель отказывает чужому персонажу, как
  сейчас читатель D&D. Навигация
  берёт вкладки из модуля выбранной системы; общие экраны (биография, заметки, кубики) переиспользуются.
- Хранение: таблица `characters` остаётся общей, у каждой системы — свои таблицы (или один JSON-документ
  листа), ключ — `characters.id`. Нынешние таблицы D&D (навыки, атаки, заклинания, инвентарь…) — таблицы
  D&D 5e.
- Тексты: строки правил системы — в её папке (`systems/<key>/localization.json`), общий файл — интерфейс.

## Этап 6. D&D 5e (2014) — ближайшая вторая система

Лист тот же, что у 2024; отличаются каталог (SRD 5.1: `external/5e-database/src/2014`) и часть правил
(происхождение, предыстории, черты, мастерство оружия). Первая проверка модульности.
